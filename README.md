# 📝 Task Manager API

Une API REST en Node.js permettant de gérer des tâches, avec une base de données PostgreSQL. Projet personnel pour apprendre les bases du développement backend.

## 🚀 Fonctionnalités

- Création de tâches
- Lecture, mise à jour et suppression de tâches (CRUD)
- Connexion à une base PostgreSQL
- Organisation du code en MVC
- (À venir) Authentification des utilisateurs avec JWT

## 🛠️ Stack technique

- Node.js
- Express.js
- PostgreSQL
- pg (module PostgreSQL pour Node)
- dotenv
- Optionnel plus tard : JWT
